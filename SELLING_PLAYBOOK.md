# First 100 RMB Playbook

## Goal

Use this repo as a lightweight commercial demo and sell the first paid customization, not a full bespoke system.

## What to sell first

Sell the `99 RMB validation version` first.

What the client gets:

- Brand name and title replacement
- Their own event or course description
- Existing career selection and dungeon flow kept as the interactive shell
- A shareable H5 demo link or static package

Why this is the right first step:

- Small decision for the buyer
- Small delivery scope for you
- Fast feedback loop
- Easier to upgrade to `299 RMB` later

## Best customer types

1. University club organizers running career-sharing events
2. Small training camps that need a more interesting recruitment page
3. Personal creators selling study roadmaps or career guidance

## Today plan

1. Pick 10 people you can message directly.
2. Send the short DM from the sales page.
3. Offer only one clear entry product: `99 RMB same-day branded version`.
4. Ask for three inputs only: brand name, target audience, destination link.
5. Close the first payment before discussing bigger customizations.

## Pricing ladder

- `99 RMB`: rename and re-skin the demo
- `299 RMB`: replace content, career directions, and resource links
- `699 RMB`: full landing page packaging and stronger signup guidance

## Delivery rules

Do not promise backend, analytics, admin systems, or unlimited revision rounds in the first order.

Keep the promise narrow:

- one theme
- one delivery round
- one revision round
- static or demo-grade deployment

## Message script

Short version:

```text
I built an interactive career-path mini game that can be re-skinned for training camps, student communities, and career events.

I can make a 99 RMB branded validation version for you today: replace title, brand, and guidance copy, then give you a sharable H5 demo.

If you want, I can send the preview and the editable items now.
```

Follow-up version:

```text
You do not need to prepare much. Just send me the brand name, target audience, and the link or contact you want users to reach.

I suggest starting with the 99 RMB version first, then upgrading only if the response is good.
```

## Practical note

The project already contains enough interactive structure to look real in a sales conversation. Your job is to sell the transformation result, not the code volume.
